# 菜单栏时区产品调研与功能设计

调研日期：2026-10-20。材料来自各项目的 GitHub 仓库、README、官方页面，以及这些页面上的界面截图。星标数取自当天的 GitHub API。

## 结论

当前面板不适合继续加控件。它把世界时钟、时间格式、搜索、系统时区切换和退出放在同一个 420×720 的弹出层里，格式又是「小时制、秒、菜单栏内容、日期」四组抽象选项，看不到最终会显示成什么样。

GitHub 上同类产品的共同做法是把界面拆成三层：

1. 菜单栏只放一条短时钟。
2. 点开后只看已添加时区的时间列表。
3. 格式、语言、外观放到独立设置窗口，并用大号预览让人直接选结果。

时区切换器要保留自己的差异：它会真正修改 Mac 的系统时区，用来测试日历、日切和排期，并且可以恢复。大多数对照产品只负责「另外显示一个时间」，不会调用系统时区命令。

界面语言和时钟格式必须分成两个设置。中文界面也可以显示 `02:05`，英文界面也可以显示 `10月21日 周三 上午 2:05`。

## 当前界面的问题

现在的弹出层同时承担「看时间」和「改软件」：

- 列表、搜索、格式分段控件、两个下拉、恢复和退出挤在一屏里。时钟不再是主体。
- 格式选项描述的是规则，不是结果。用户无法像选模板一样看到 `PDT 02:05` 和 `10月21日 周三 上午 2:05` 的差别。
- 没有界面语言设置。中英文文案虽然都在，但只跟随 macOS 语言，不能在软件里指定。
- 菜单栏文本和列表时间共用一套零散开关，改一项会同时影响两处，又看不出菜单栏最终长什么样。

## 界面上反复出现的做法

**菜单栏很短，而且能看出不是系统时钟。** ZonePeek 用时钟图标加 `7月4日 周六 上午 9:02`。TimezoneBar 在模仿系统时钟的文字前加城市缩写 `LOS`。TZBar 钉住时显示旗帜加 `17:10`。World Clock 会把多个城市排进菜单栏，城市一多就会占满状态栏，不适合作为默认。

**点开之后先看到时间，不是表单。** TZBar 和 There 的弹出层都是一行一个时钟，时间靠右对齐。编辑、删除、钉到菜单栏放进行菜单。设置是角落里的齿轮，打开另一扇窗口。

**格式用结果来选。** ZonePeek 的「显示格式」页先给一行很大的预览，例如 `23:57:23` 或 `7月4日 周六 上午 12:01`，下面每张卡片同时写中文名称、渲染结果和 pattern（`HH:mm:ss`、`M月d日 E a h:mm`）。World Clock 的设置窗口则用一个时间格式下拉，选项本身就是 `hh:mm AM/PM`。两种都比「打开显示秒、再选日期策略」容易懂。ZonePeek 还写明：不懂 pattern 也没关系，先从常用样式里选。

**中文是格式，不是自动等于界面语言。** 看过的产品都没有单独的「界面语言：中文 / English」开关。ZonePeek 和 TimezoneBar 用系统语言或一条「中文日期时间」预设来解决中文显示。这解决不了「界面要英文，但时钟要中文日期」或相反的情况。时区切换器需要把这两件事分开。

**自定义名称比 IANA 标识更适合放在主行。** World Clock 把 `Asia > Calcutta` 显示成 India。There 把洛杉矶显示成 LA office。TZBar 的主行是 Montreal、France，不是 `America/Toronto`。标识适合放次要位置，避免一行里堆按钮。

## 产品定位

时区切换器仍然是 macOS 菜单栏工具，服务需要临时改系统时区的人：确认日历、订阅、账期、午夜和只在某个时区出现的问题。用完可以回到原来的系统时区。

它同时是一份小型世界时钟。已添加的城市都显示自己的当地时间。系统改到洛杉矶之后，上海那一行仍然是上海时间。

菜单栏上的那一条时钟，用来在系统时钟已经被测试时区接管之后，继续看到自己想看的时间。这和 ZonePeek 的使用场景相同，但切换和恢复由本软件完成，不需要用户再去系统设置里改。

## 功能设计

### 1. 三个界面

```text
菜单栏          一条图标 + 按所选格式显示的一个时间
弹出面板        已添加时区的时间列表，加上添加和恢复
设置窗口        显示格式、界面语言
```

弹出面板不再放格式表单、语言和退出以外的管理项。退出可以留在弹出面板底部，和 TZBar、World Clock 一样作为最后一项。格式和语言只出现在设置窗口。

### 2. 菜单栏

- 始终保留一个时钟图标，后面跟着格式化文本。只有图标时，覆盖开启用带勾的时钟，覆盖关闭用普通时钟。
- 同一时间只显示一个时区。显示对象三选一：仅图标；自动（覆盖关闭时仅图标，覆盖开启时显示当前系统时区）；固定为列表中的某一个。
- 文本使用设置里选中的格式，不再在格式之外再拼一层缩写或日期。
- 不显示秒时按分钟刷新。格式里带秒时按秒刷新。
- 建议默认格式是「缩写和时间」，例如 `PDT 02:05`。这样在系统时钟旁边也能看出它属于哪个时区。用户可以改成 TimezoneBar / ZonePeek 那种带日期的长文本。

### 3. 弹出面板

面板只回答「现在各地几点」。

每一行：

- 主标题是自定义名称。新建时默认用本地化城市名或时区名，用户可改成「公司」「家里」。
- 次行保留 IANA 标识，避免「中国标准时间」这类名称产生歧义。
- 右侧是该时区的当地时间，使用同一套显示格式里的时间部分。跨天时在时间下显示短日期，或「昨天 / 今天 / 明天」。
- 这一行若是当前 Mac 时区，标「系统」。覆盖期间的原始时区标「本机」。

行上的操作收进菜单，不把三个图标按钮铺在每一行上：

- 设为系统时区
- 在菜单栏显示
- 重新命名
- 删除

底部：

- 添加。点了才出现搜索。搜索支持本地化名称、城市、IANA 标识。已添加的不再加入。添加本身不改变系统时区。
- 覆盖开启时显示「恢复本机时区」。
- 齿轮打开设置窗口。

列表可以拖动排序。空列表时用一句话说明：搜索并添加一个时区。

### 4. 设置窗口：显示格式

独立窗口，顶部固定一块大号预览，内容就是菜单栏将要显示的字符串，并注明它来自哪个时区。预览随选择立即变化。

预设卡片，每张同时给出名称、示例和 pattern：

| 预设 | 示例 | pattern |
| --- | --- | --- |
| 仅时间 | `02:05` | `HH:mm` |
| 缩写和时间 | `PDT 02:05` | `z HH:mm` |
| 紧凑日期 | `10-21 02:05` | `MM-dd HH:mm` |
| 中文日期时间 | `10月21日 周三 上午 2:05` | `M月d日 E a h:mm` |
| 英文日期时间 | `Wed Oct 21 2:05 AM` | `E, MMM d, h:mm a` |
| 自定义 | 用户输入的结果 | 用户输入的 DateFormatter pattern |

卡片下用一句说明：可以先选常用样式。自定义时列出常用符号：`HH` 24 小时，`h` 12 小时，`mm` 分，`ss` 秒，`a` 上午/下午，`E` 星期，`z` 时区缩写，`M月d日` 这种字面量会原样出现。

「显示秒」只作为当前预设的附加项，打开后在 pattern 的分钟后加 `:ss`。不再和日期策略分成另一组互不相干的开关。

这套格式同时用于菜单栏和列表里的时间。列表在跨天时仍可多画一行短日期，避免菜单栏选了「仅时间」之后，弹出层看不出已经是第二天。

### 5. 设置窗口：界面语言

语言单独一栏，三个选项：

- 跟随系统。默认。
- 简体中文。
- English。

它决定按钮、说明、时区本地化名称和搜索所使用的语言。它不决定菜单栏是 `上午 2:05` 还是 `02:05`，那由显示格式决定。

选择保存在本机。切换后，弹出面板和设置窗口下一次刷新就使用新语言，不需要管理员权限，也不需要为了换语言去改 macOS 系统语言。

时区名称跟随这个选择。选简体中文时，`America/Los_Angeles` 的显示名使用中文区域；选 English 时使用英文。IANA 标识始终原样保留。

### 6. 系统时区

这部分保持已经确定的规则，只改入口，不改语义。

- 第一次从真实系统时区切走时，记下当时的时区为本机时区。若它不在列表里，插到最前面。之后在洛杉矶、上海之间切换，不覆盖本机记录。
- 若选中的城市已经是当前系统时区，不开启覆盖。
- 覆盖期间再选择本机时区，等于恢复：系统切回，列表保留，清除覆盖状态。
- 覆盖期间不能删除本机时区。
- 删除当前系统时区时，先恢复成功，再从列表删除。用户取消授权时列表不变。
- 删除的只是菜单栏固定项时，不改系统时区，菜单栏回到自动。
- 先执行系统命令，成功后再写入软件状态。

设为系统时区和恢复仍然是唯一需要管理员授权的操作。改格式、改语言、改菜单栏显示对象都不需要。

### 7. 两个设置为什么分开

以洛杉矶凌晨 2:05、日期为 10 月 21 日为例：

- 界面语言「简体中文」+ 格式「仅时间」：按钮是中文，菜单栏是 `02:05`，时区名是中文。
- 界面语言「English」+ 格式「中文日期时间」：按钮是英文，菜单栏是 `10月21日 周三 上午 2:05`。
- 界面语言「跟随系统」+ 格式「缩写和时间」：界面跟 macOS，菜单栏是 `PDT 02:05`。

ZonePeek 把「中文日期时间」做成格式卡片，TimezoneBar 让菜单栏跟着系统语言长得像系统时钟。两边都说明：时钟字符串和软件界面不是同一件事。

## 这一版范围

做：

- 弹出面板改成时间列表，操作收进行菜单。
- 设置窗口：格式卡片加大号预览，语言三选一。
- 菜单栏按所选格式显示一个时区，并保留图标。
- 继续支持多时区、设为系统时区、恢复本机时区。

先不做：

- 日历、会议和一键加入通话。那是 Clocker、MeetingBar 的产品。
- 联系人头像。那是 There 的产品。
- 菜单栏同时钉住多个时钟。World Clock 的截图里三个城市已经排得很长。
- 拖动滑杆预览其他时刻。TZBar 的滑杆只改变显示，不改变系统时间；放在会真正改系统时区的软件里，容易让人以为 Mac 的时间也被拖走了。
- 从某个假时间继续走动。ZonePeek 的自定义时间来源适合以后单独做测试时钟，不和系统时区切换混在同一个开关里。
